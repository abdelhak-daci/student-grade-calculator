# Student Grade Calculator

A simple Python application that calculates a student's average grade
and determines whether the student passes.

## Features

- Calculate the average of a list of grades.
- Determine whether a student passes.
- Categorize grades as Excellent, Good, Average, or Fail.

## Requirements

- Python 3.11 or later
- pytest
- flake8
